## 🚀 Available Scripts

In the project directory, you can run:

### `npm start`
Starts the **development server**.

### `npm run build`
Bundles your website into **static files for production**.

### `npm run serve`
Serves the **built website locally**.

### `npm run deploy`
Publishes the website to **GitHub Pages**.
